# Innloggingsbro for admin-panelet

Samme oppsett som Oliva Park. Du kan gjenbruke den eksisterende Worker-en og GitHub OAuth-appen (se oauth-worker i Oliva Park-repoet), siden den ikke er knyttet til én enkelt nettside. Config peker allerede på den.

Vil du ha en egen: følg stegene i Oliva Park sin README, og bytt `base_url` i `src/admin/config.yml`.
